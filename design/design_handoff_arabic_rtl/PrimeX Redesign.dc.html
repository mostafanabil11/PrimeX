Decisions here

The signed-out state is the design

This is the only step that can bounce someone to another page and back. The copy promises the return trip and that the plan survives it, because the unspoken fear is losing the selection. Worth verifying the round trip actually preserves it — the funnel keeps plan state in the component, so a full navigation to /signup and back may not.

Fields stay visible while locked

Dimmed at 45% rather than hidden, so the length of the step is honest before you commit to the detour. Hiding them makes signing up feel like it leads somewhere unknown.

Identity is a receipt, not a field

Name and email confirmed in one 60px row with a green check and a quiet "Not you?" — the current build spends a five-line panel on this. The email truncates rather than wraps.

Emergency contact gets a reason

"Who we call if something happens on the floor." One line, and it converts an intrusive-feeling demand into an obviously sensible one. It's also the honest answer.

Relationship becomes chips

Five taps instead of a free-text field whose placeholder already listed the answers. Keep "Other" opening a text input. This is a small API question: the field is a free string today, so chips write the same string.

Inputs at 16px

The codebase already does this (text-base md:text-[14px]) — anything smaller makes iOS Safari zoom on focus and the user has to pinch back out mid-form. Worth stating so it survives a future tidy-up.

Back appears in the bar

From step 2 onward the sticky bar carries a 48px back arrow before the total. Already built in StickyTotal; shown here so the spacing is checkable.

Notes on the RTL port

Every offset here is a logical property — margin-inline-start, inset-inline-start, text-align:start — so the layout mirrors with no second stylesheet. Your codebase already writes them this way.

Three things do not mirror. Chevrons and the back arrow are flipped explicitly with scaleX(-1). Latin currency figures keep dir="ltr" so "EGP 22,780" does not reorder. The brand lockup stays as drawn.

Anybody has no Arabic coverage, so the display voice needs a second face. Noto Kufi Arabic at 800 is the closest match in weight and squareness — upright rather than slanted, because a synthesised Arabic italic reads as a rendering fault. Body and label text share it, which keeps the Arabic page to one family instead of three.

Arabic-Indic numerals in prose, Latin in prices. That mix is what Egyptian sites do in practice and it is worth confirming with the gym before it ships.
